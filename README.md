## Definition of Done

- [x] Code runs locally with Live Server, no errors in the Console
- [x] Manifest and service worker show no errors in DevTools > Application
- [x] Installs from Chrome on the laptop and opens in its own window
- [x] Loads offline (tick "Offline" in DevTools, reload, page still shows)
- [x] Committed to Git and pushed to GitHub
- [x] Live on GitHub Pages over HTTPS, and still installable from the live link
- [x] Tested on my Samsung phone from the live link (Add to Home screen) and opens full screen
- [x] Lighthouse run on the live URL, with no red scores in Accessibility or Best Practices
